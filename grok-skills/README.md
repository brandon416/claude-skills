# C-Suite overlay (Grok-first, multi-runtime)

Two skills every agent should load. The rest of the repo is depth.

| Skill | Slash | Description |
|---|---|---|
| **orchestrate** | `/orchestrate` | Chief-of-staff router. Classifies a messy founder question, seats 1–5 C-suite chairs, or convenes a boardroom. |
| **ceo-assistant** | `/ceo-assistant` | CEO seat with CoS discipline. Strategy, capital allocation, board narrative, time leverage. Delegates everything else. |

Also in this folder:

- `agents/` — 13 C-suite voices with Claude-only tool lists and `~/.claude/` paths removed
- `AGENTS.md` — project rules for Cursor, Hermes, Codex, and Grok

Install: see [`GROK.md`](../GROK.md) at the repo root.

These documents are intentionally valid for **Grok Build, Codex, ChatGPT, Hermes Agent, and Cursor**. Do not add runtime-specific tool names to the skill bodies.
